# 🏠 HomeMend

> We Mend, You Rest.

HomeMend is a SaaS-based Home Repair & Tech Support platform that connects users with verified technicians for home maintenance and technology repair services.

From laptop repairs and appliance servicing to electrical fixes and smart home equipment support, HomeMend provides a seamless way to book, track, and manage repair services online.

---

## 🚀 Features

### 👤 User Features
- User Registration & Authentication
- Browse Available Services
- Book Repair & Maintenance Services
- Service Scheduling
- Track Order Status
- Service History Management
- Profile Management
- Cart & Checkout System

### 🛠 Technician Features
- Technician Dashboard
- View Assigned Jobs
- Accept / Reject Requests
- Update Service Progress
- Manage Work Schedule

### 👨‍💼 Admin Features
- Manage Service Categories
- Monitor Bookings
- Manage Users & Technicians
- Assign Service Requests
- Platform Administration

---

## 🎯 Problem Statement

Finding trustworthy repair professionals for home and technology-related issues remains difficult despite the rise of digital services.

Users often face:

- Unverified technicians
- Inconsistent pricing
- Delayed responses
- Lack of transparency
- Poor service tracking

HomeMend solves these challenges by providing a centralized platform where users can discover, book, and monitor professional repair services with confidence.

- Admin

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/shub-360/HomeMend.git
```

### Navigate to Project

```bash
cd HomeMend
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
